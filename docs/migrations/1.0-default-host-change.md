# 1.0 default service host change (Thenvoi → Band)

> **Lead item for the 1.0 release notes.** This is a silent runtime default
> change: it retargets any consumer that never passed an explicit URL, with no
> compile error and no warning.

## What changed

- The SDK's default WebSocket URL moved from `wss://app.thenvoi.com/api/v1/socket`
  to `wss://app.band.ai/api/v1/socket` (`packages/sdk/src/platform/BandLink.ts`).
- The default REST URL is derived from the WS host (`deriveDefaultRestUrl`), so it
  moved with it: `https://app.thenvoi.com` → `https://app.band.ai`.
- The Linear bridge's user-visible deep-link base moved to `https://app.band.ai`.
- The SDK defaults are now byte-identical to OpenClaw's existing `app.band.ai`
  defaults and to `BandEnvironment.Default` in `@band-ai/rest-client`.

## Escape hatch (pin the legacy host)

Passing an explicit `wsUrl` / `restUrl` is byte-preserved. The platform continues
to serve API requests and WebSocket upgrades on `app.thenvoi.com` (only browser
traffic is redirected off the legacy host), specifically because published 0.x
SDKs carry that host as their default. To stay on the legacy host, pass it
explicitly:

```ts
new BandLink({
  agentId, apiKey,
  wsUrl: "wss://app.thenvoi.com/api/v1/socket", // restUrl derives to https://app.thenvoi.com
});
```

Passing an explicit `restUrl` overrides the derived value independently.

## Environment variables

The env prefix default moved from `THENVOI_` to `BAND_`, with a per-field
fallback to the legacy `THENVOI_` variable (Band wins independently for
`AGENT_ID`, `API_KEY`, `WS_URL`, `REST_URL`). Each legacy variable used emits a
one-time deprecation warning naming the old variable and its Band replacement —
never a secret value. A custom prefix (including an empty string) is used
exactly, with no fallback. OpenClaw account fields still take precedence over
env, and its legacy env fallback now emits the same once-per-variable warnings.
OpenClaw E2E reads `BAND_API_KEY_USER` first, falling back to the E2E-only
legacy `THENVOI_API_KEY_USER`.
